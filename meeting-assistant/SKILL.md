# 会议助理 Skill

将零散原始资料整理成可以独立阅读、复制和复习的笔记。默认中文，保留必要的英文术语；会议资料输出纪要，授课资料输出知识笔记，不把授课强行改成待办和决议表。

## 先识别任务与资料

- 接收录音文件、音频链接、听悟／妙记等分享页面、转写初稿、课件网页／PDF／图片，以及已有笔记。资料不必齐全，先处理可访问部分。
- 用户有明确输出要求时直接执行。通常不再询问语言、标题层级、是否要图文版等已经有默认值的问题。
- 修改已有笔记时保留已接受的内容和结构，重点落实新增要求；补课件时把信息放到对应章节，不在文末堆放一份无关摘要。
- 通过当前环境可用的连接器、浏览器、文件或音频工具读取资料。不得假设某个浏览器、ASR、API Key 或付费服务已经可用。
- 分享页加载或登录失败时，先确认实际页面状态；仍无法读取则具体说明缺少哪份资料，请求可访问链接、导出稿或本地文件，继续完成不依赖它的工作。

## 读全、对齐与纠错

1. 区分原始逐字稿、平台 AI 摘要、用户备注和课件内容。平台概要用于导航，不能替代原文。
2. 长稿逐段读取；虚拟滚动页面要覆盖开头、中段、结尾，合并重叠段落并检查缺口。多份录音按课程顺序或主题对应，不默认是同一场内容。
3. 已有转写可用时先复用。需要听音校对且音频可访问时，针对疑点复核；没有文字或确需重新转写时，再调用可用 ASR。不要为了运行 Skill 而无条件安装模型、重复处理全部录音。
4. 用原音、课件、上下文和术语表交叉检查同音字、人名、产品名、缩写、单位和数字。明确证据支持时修正；不能因为读起来顺畅就擅自补字或确定专名。
5. 课件只补充相关事实、关系和步骤，不能抹去录音里额外的案例。若课件含录音未涉及的后续实操，可按教学顺序补入，但不能声称录音已经演示或完成。
6. 不确定项不伪装成确定事实。非关键数字可以省略；关键疑点保留最小的“待确认”标记，或写入独立来源记录。不要在主笔记中重复插入整段免责声明。

## 默认写法：直接呈现内容

生成前阅读 [写作要求与改写示例](references/writing-style.md)。以下是核心约束：

- 面向一个未听过原始课程或会议的读者，直接解释概念、关系、方法和例子。
- 避免“老师说／老师讲／老师分享”“课堂提到”“会议中分享了什么”“这部分主要传达的是”等转述外壳。
- 例子用“举例：”引入，写清背景、做法和结果／启示。保留报价、意向、成交之间的区别，不把讨论写成既成事实。
- 对来源中的主观工具体验，可写“个人体验下来……”或“从实际使用体验看……”。这是整理来源的口吻，不能捏造助理亲测经历，也不把体验排名写成客观定论。
- 主笔记不出现“回看位置”、逐段时间戳、来源识别过程和“录音中的价格仅供参考，不构成建议”等模板话。用户明确要求时间索引时再增加。
- 删除寒暄、重复、口头禅和跑题内容；保留推理关系、具体案例、关键参数、操作步骤与可验证的验收标准。
- 不强制固定章节数或套用旧课程标题。可按“目标 → 概念 → 流程／架构 → 方法／选型 → 案例 → 实操／复习”组织，主题决定实际结构。
- 真正的会议纪要需保留已确认的决议、任务、负责人、期限和未决问题；没有明确负责人与截止日就标待定，不自行指派或编造。

## Markdown 与图文组织

- 默认一个 `#` 总标题，正文使用 `##` 二级标题；更细的内容用加粗短标题。不要用三级及以下标题。
- 使用正常 Markdown：段落、列表、对照表、必要的代码块与相对图片路径。加粗标记旁留合适空格，检查是否实际渲染，避免把 `**举例：**` 原样显示出来。
- 只在信息适合比较时用表格；复杂关系优先用课件原图，没有合适原图再考虑简单示意图。用户只要文字时不强行制作图片。
- 图文任务阅读 [课件配图与交付](references/illustrated-notes.md)，选择能解释关系的图，放在相应知识点下方，并写出读图结论。图不能代替完整说明。

## 交付与检查

普通任务直接提供可复制正文及 `.md` 文件。图文任务默认同时提供：

- Markdown 与相邻的 `assets/` 图片目录；
- 图片内嵌的独立 HTML 图文预览；
- 包含 Markdown、预览和实际引用图片的 ZIP。

可以使用 `scripts/package_notes.mjs` 生成图文交付。只想写文字时不必安装脚本依赖。依赖准备和参数见 [图文交付说明](references/illustrated-notes.md)。脚本只包装已写好的笔记，不负责抓取、转写或生成内容。

交付前确认：

- 内容覆盖主要主题，纠错不越过证据，数字与案例的状态没有被加强；
- 用户最新的写法要求已落实，不残留转述外壳和回看时间；
- 只使用一级、二级标题，表格和加粗可正常渲染；
- 图片与相邻文字相符，中文和箭头清晰，PNG 没有截断或透明底导致的缺失；
- 图片链接有效，HTML 可离线显示，ZIP 不夹带录音、凭据或其他未引用文件；
- 未实际复听、测试、生成或验证的事项不宣称已完成。

最终回复简要说明新增了什么并给出文件入口；用户要求重新输出全文时，直接给完整笔记。需要说明来源读取限制时，放在交付说明中简短交代，不污染正文。

本 Skill 的调用只授权整理资料和生成本地交付物；发布到 GitHub、写入飞书或向他人发送内容仍需用户相应指令。
